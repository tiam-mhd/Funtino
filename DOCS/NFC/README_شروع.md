# بستهٔ پرامپت موجودی NFC کارت Funtino Web

## فایل‌ها

- `01_Prompt_اجرایی.md` — پرامپت اصلی برای اجرا در مخزن `tiam-mhd/Funtino`.
- `02_راهنمای_معماری_و_منطق.md` — یافته‌های source از Windows و Web و تفاوت موجودی چیپ با snapshot Wallet.
- `03_قرارداد_پل_خوانش.md` — قرارداد پیشنهادی بین رابط وب، lookup سرور و reader/native bridge.
- `04_معیارهای_پذیرش.md` — چک‌لیست امنیت، UX، API، تست و تأیید سخت‌افزار.

## نکتهٔ فنی تعیین‌کننده

در Windows موجودی از بلوک ۸ کارت پس از احراز هویت با کلید شش‌بایتی خوانده می‌شود. Web NFC در مرورگر همان دسترسی low-level را ندارد. بنابراین اسکن UID و نمایش snapshot کیف‌پول، با خواندن مستقیم موجودی فیزیکی کارت یکی نیست. پرامپت صریحاً جلوی این ادعای نادرست و قراردادن کلید در JavaScript را می‌گیرد.

## روش استفاده

1. مخزن Web را در Codex باز کن.
2. فایل `01_Prompt_اجرایی.md` را کامل به‌عنوان prompt بده و سه فایل دیگر را همراهش در اختیار Codex قرار بده.
3. در پایان، وضعیت موارد «پاس/رد/تأییدنشده» فایل معیارهای پذیرش را همراه با خروجی build و تست‌ها بخواه.

این بسته خودش پروژه را تغییر نداده و هیچ commit یا push انجام نداده است؛ برای اجرا در مخزن وب آماده شده است.
