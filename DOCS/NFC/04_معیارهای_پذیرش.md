# معیارهای پذیرش: NFC و نمایش موجودی کارت

این چک‌لیست برای بازبینی پایان کار است. وضعیت هر ردیف باید `پاس`، `رد` یا `تأییدنشده` باشد؛ تست mock یا build به‌تنهایی تأیید سخت‌افزاری نیست.

## ۱. رفتار کارت و تطبیق با Windows

## معیار رد فوری

هرکدام از موارد زیر یعنی قابلیت آمادهٔ انتشار نیست:

- ادعای خواندن مستقیم بلوک ۸ فقط با Web NFC، بدون bridge واقعی.
- ارسال یا نگهداری key کارت در frontend.
- نمایش balance stale/pending به‌عنوان موجودی فعلی.
- lookup بدون احراز هویت مشتری یا بدون محدودکردن به branch.
- پاسخ عمومی حاوی UID/hash/cardId یا اطلاعات خانواده/عضو.
- استفاده از mock دائمی برای اعلام اتصال به NFC واقعی.
- ایجاد هرگونه مسیر نوشتن روی کارت یا mutation مالی.
- تغییر نام catalog دیتابیس یا اجرای migration/backfill تولیدی بدون مجوز.

## گزارش اجرای این پیاده‌سازی — ۲۰۲۶-۱۱-۲۲

- مسیر پیاده‌شده در Customer و Operations فقط از Web NFC برای دریافت NDEF و شناسهٔ سریال قابل‌دسترسی مرورگر استفاده می‌کند. شناسه در حافظهٔ کوتاه‌عمر به hash تبدیل و فقط در body درخواست `POST` برای lookup فرستاده می‌شود.
- منبع مبلغ هر دو رابط، projection تازه و تأییدشدهٔ Wallet مرکزی است. این قابلیت بلوک فیزیکی ۸ کارت را نمی‌خواند و مبلغ Wallet را به‌عنوان موجودی چیپ معرفی نمی‌کند.
- مسیر پل بومی/کارت‌خوان مورداعتماد در این مخزن موجود یا پیاده‌سازی نشده است؛ ترتیب فرمان‌های Windows، خواندن بلوک ۸ و مقایسهٔ کارت واقعی تأییدنشده‌اند. هیچ تغییر یا قراردادی در مخزن Windows انجام نشد.
- تست hash فقط از fixture بردار طلایی `01020304` استفاده می‌کند. گوشی، مرورگر و کارت واقعی در این محیط در دسترس نبودند؛ نتیجهٔ fixture تأیید سخت‌افزاری محسوب نمی‌شود.
- مجوز Operations با کلید مستقل `card.balance.read` اضافه شده و به نقش‌ها یا tokenهای Edge موجود به‌طور پیش‌فرض داده نشده است.
- `pnpm.cmd --filter @funtino/nfc-reader test`: ۴ از ۴ پاس.
- `pnpm.cmd --filter @funtino/customer-web test`: ۱۰ از ۱۰ پاس.
- `pnpm.cmd --filter @funtino/operations-web test`: ۲۲ از ۲۲ پاس.
- `pnpm.cmd --filter @funtino/api-gateway test`: ۱۱۶ از ۱۱۶ پاس.
- `pnpm.cmd --filter @funtino/wallet test`: ۳۷ تست Wallet و ۱۷ تست startup، همگی پاس.
- `pnpm.cmd --filter @funtino/identity-access test`: ۹۷ تست IAM و ۱۷ تست startup، همگی پاس.
- `pnpm.cmd typecheck`، `pnpm.cmd lint`، `pnpm.cmd contracts:check`، `pnpm.cmd test` و `pnpm.cmd build` موفق شدند. lint فقط warningهای قبلی در فایل‌های نامرتبط گزارش کرد.
- هیچ migration یا backfill تولیدی اجرا نشد و نام database/catalogها تغییر نکرد.
- نتیجهٔ سخت‌افزاری و پل فیزیکی همچنان «تأییدنشده» است؛ تا انجام آزمون با کارت و دستگاه واقعی، معیار خواندن مستقیم چیپ پاس محسوب نمی‌شود.
